## 💬 使用範例！

下面三段是真實測試，不是示意圖。

### Case 1：不太懂技術的人，可簡單說「網站壞了」

> **你：** 我的網站好像壞了，怎麼辦？
>
> **站長：** 「好像壞了」有很多種可能，我先問三件事就好。
> 現在打得開嗎？打開看到什麼？主機後台有沒有紅色警告？
>
> **你：** 打得開，但畫面都白的。
>
> **站長：** 白畫面通常是外掛或佈景壞掉。這件事我現在還不能幫你動手
> （原因寫在下面「安全限制」），但我可以告訴你下一步怎麼確認，不會讓你亂試。
>
> **需要我詳細解釋嗎？**

**它沒有裝懂，也沒有丟一堆指令給你。**

---

### Case 2：專業人士可直接問專業技術問題

> **你：** wp-admin 回 500，error_log 顯示 PHP Fatal error: Allowed memory size exhausted
>
> **站長：** 這則訊息是「記憶體用盡」，但兩種完全相反的成因，處理方式相反：
> - 情況 A：上限設得太小
> - 情況 B：某個東西吃太多
>
> 先看 bytes 數字就能判斷。41943040 是 40M，也就是 WP 單頁的預設值，
> 134217728 是 128M，多數外掛都建議至少給到這裡。
>
> **最後這段是重點。** 下一個要改的是 wp-config.php 裡的 `WP_MAX_MEMORY_LIMIT`。
> 這個常數**不在自行修改的既定清單內**，屬於需要另外明確設定、
> 並經過二次確認的等級。
>
> **我不會擅自改它。**

**它知道自己的權限邊界，而且會說出來。**

---

### Case 3：安全先看看問題，你可說「只看問題先不要改」

> **你：** 只給我看，不要改。我的網站有沒有問題？
>
> **站長：** 你說的「只給我看」模式已經開啟，**我不會動任何東西**。
>
> 我會給你一份「問題、影響、建議」的報告。裡面要動手的部分會另外標示，
> **等你講一句「可以動手了」**，我才會真的去做。

## 🛡️ 為了安全，我們限制了什麼？

> [!IMPORTANT]
> **一句話承諾：目前的版本「絕對不會自動動你的網站」。**  
> 網站會壞，通常是因為動得太快、而且沒留退路。我們先把「不亂動」這件事做到極致，才來談「幫你做事」。

### 🛑 我們給 AI 設下的 3 道硬限制

1. 🚫 **只看不改，絕不擅自動手**：目前它只負責「診斷問題、分析原因、給出建議」。就算你要求它改，它也只會告訴你步驟，**絕不會直接連進去改動你的網站**。
2. 🔒 **危險操作，必須你親自點頭**：碰到修改代碼、調整資料庫等高風險操作，沒有你的明確同意，它一律停手不動。
3. 📦 **備份優先，永遠留好退路**：所有技術規範都以「隨時能一秒還原」為第一優先，絕不讓你承擔網站壞掉的風險。

### 📊 功能開放狀態一覽

| 🟢 現在就能放心用（完全不碰網站） | 🟡 為了安全，暫時不開放自動動手 |
|:---|:---|
| 💬 **白話諮詢**：像問資深站長一樣討論網站問題 | ⏳ **自動批次改文章**（避免批量誤改內容） |
| 🔍 **錯誤排查**：貼上報錯訊息，幫你解讀成白話 | ⏳ **自動改代碼 / 外掛設定**（安全測試中） |
| 🧭 **步驟指引**：告訴你下一步該如何確認或找誰修 | ⏳ **一鍵自動連接主機**（避免權限過大） |

> **安心保證**：在各項安全網完全通過驗收前，它**只會跟你對話，不會動你的網站**。

### ❓ 這是什麼

想像你請了一個站長。

他不住你家，你不用付月薪，也不用替他準備一張辦公桌，因為他就住在你平常在用的
AI 裡面。打開電腦或手機，都找得到他。

你跟他說「網站好像怪怪的」，他知道該先從哪裡看起。你跟他說「幫我改個標題」，
他會先問是哪一篇、要改成什麼。你跟他說「全部幫我處理好」，他不會馬上動手，
會先寫一張清單問你。

**這就是那個站長的腦袋。**

它不是網站，也不是 App，更不需要註冊帳號。它是一份寫得很細的說明書，
把「一個好站長該怎麼做事」一條一條寫下來，再裝進你本來就在用的 AI 就好
（Claude、Codex、Cursor 這一類都行）。

**它不會自己連上你的網站。**

要真的動手，得靠你的 AI 和你給它的權限。它管的事情只有一件：
該不該做，以及怎麼做才安全。

### 🔐 安全設計

#### 🧱 七層安全網

每一個會寫入網站的操作，都必須依序走完這七步，一步都不能跳：

1. **備份**：匯出資料庫、打包檔案。失敗就換方案，四種都失敗才進入風險說明
2. **先給你看要改什麼**：列出將要改的具體內容，不接受「優化 SEO」這種模糊說法
3. **確認**：依風險等級取得你的明確同意
4. **可逆標記**：每一項都標明「可逆」或「不可逆」
5. **先在測試站試**：高風險操作先在測試站驗證
6. **留下操作紀錄**：每個動作留一行紀錄，只增不改
7. **自動還原**：失敗自動還原。還原失敗立即停止，並交你手動步驟

#### 🚦 操作分級

| 級別 | 意思 | 站長怎麼做 |
|---|---|---|
| **G0 只看不改** | 不改任何東西 | 直接執行 |
| **G1 可逆變更** | 改內容但能還原 | 提案後等你確認 |
| **G2 高風險** | 改檔案、外掛、主題 | 必須明確同意 + 備份 + 先在測試站試 |
| **G3 禁止** | 不可逆或會毀站 | 預設拒絕，除非你用自己的話二次明確要求 |

G3 的具體清單，這些它一律不碰：

- 直接寫入資料庫
- 刪掉 wp-content
- 改 wp-config 的資料庫憑證與安全金鑰
- 更換主題
- 停用全部外掛
- 重設資料庫
- 刪掉 Cloudways server

**而且 wp-config.php 有特別的規矩。**

它只允許四個特定的設定項目可以改，其他一律不准碰。因為這個檔案一旦改錯，
整站會變成白畫面，連後台都進不去。

#### 🔧 弄壞了會怎樣

站長會**先備份才動手**，失敗會自動還原。

如果真的連還原都失敗，它會立刻停下來，並留一份手動還原步驟給你，
裡面含備份識別碼和還原順序，你照著做就能回到原狀。

### 🧩 還需要裝什麼

**只有一樣：BrowserOS neo。**

沒有 SSH 的時候，它就是站長的手：讓 AI 借用你瀏覽器裡已經登入的狀態，
直接操作網站後台，不用碰你的密碼。

BrowserOS neo 免費、開放原始碼，不需要帳號，也不需要 API key。它是一個獨立瀏覽器，
跟 Chrome 並存，首次開啟可以一鍵匯入 Chrome 的書籤與密碼。

下載：https://www.browseros.com/download/

裝好後開一次就好，它會自動偵測你電腦上的 Claude Code、Codex 或 Cursor，
按一下就能連上，不需要改任何設定檔。

**其他都是授權，不是安裝：**

- WordPress 授權 → 在後台產生一組「應用程式密碼」
- 主機授權 → 給一組 SSH 金鑰或 Cloudways API Key

### 🎛️ 怎麼控制它

平常你不用管它，它會自己照上面的規矩走。但如果你想插手，這四句話最快：

```text
「只給我看，不要改」        → 只看不改模式
「可以動手了」              → 解除
「先備份再做」              → 強制先備份
「給我看 log」              → 看操作紀錄
```

這四句是開關，不是咒語。用你平常講話的語氣說就行，它聽得懂。

### 🙋 FAQ

**Q：免費嗎？**

是，永久免費，原始碼全部公開。你可以自己看、自己改。

**Q：需要會寫程式嗎？**

不需要。站長預設假設你不懂技術，會用白話和比喻說明。你可以隨時說「講詳細一點」
切換成技術模式。

**Q：一定要用 Cloudways 嗎？**

不用。但四層快取的自動消退、伺服器層操作（重啟、SSL、備份還原）
只有在 Cloudways 上才做得到。其他主機它會直接告訴你哪幾項不行。

**Q：它會自己改我的網站嗎？**

不會。每一個寫入操作都要你同意，而且會先列出「將要改什麼」讓你確認。

**Q：如果它改壞了怎麼辦？**

七層安全網的第一層就是備份，失敗會自動還原。你也可以在事前要求「先備份再做」。

**Q：支援哪些 AI？**

Claude Code、Codex、Cursor、OpenCode，以及任何支援 `SKILL.md` 格式的 Agent。

**Q：跟一般叫 AI 幫我改網站有什麼不同？**

一般 AI 會直接給你指令或直接動手。這個 skill 給它的是「判斷力」：
什麼該做，什麼要先問，什麼絕對不能碰，以及出問題時怎麼收拾。

**Q：為什麼叫「站長」？**

因為它要模擬的不是「工具」，是「一個幫你顧網站的人」。
