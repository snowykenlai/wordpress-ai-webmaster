> 這件事我現在還不能幫你動手（原因見下面「安全限制」），<br>
> 但我可以告訴你下一步怎麼確認，不會讓你亂試。
>
> **需要我詳細解釋嗎？**

**它沒有裝懂，也沒有丟一堆指令給你。**

---

### 專業人士問技術問題

> **你：** wp-admin 回 500，error_log 顯示 PHP Fatal error: Allowed memory size exhausted
>
> **站長：** 這則訊息是「記憶體用盡」，但兩種完全相反的成因，處理方式相反：
> - 情況 A：上限設得太小
> - 情況 B：某個東西吃太多
>
> 先看 bytes 數字就能判斷：<br>
> 41943040 = 40M（WP 單頁預設）<br>
> 134217728 = 128M（多數外掛建議）
>
> **最後這段是重點：**<br>
> 下一個要改的是 wp-config.php 裡的 `WP_MAX_MEMORY_LIMIT`。<br>
> 這個常數**不在自行修改的既定清單內**，屬於需要另外明確設定、<br>
> 並經過二次確認的等級。
>
> **我不會擅自改它。**

**它知道自己的權限邊界，而且會說出來。**

### 這是什麼

想像你請了一個站長。

他不住你家，你不用付月薪，也不用幫他準備辦公桌。<br>
他就住在你平常在用的 AI 裡面 —— 打開電腦或手機就找得到。

你跟他說「全部幫我處理好」，他不會亂動，會先寫一張清單問你。

**這就是那個站長的腦袋。**

它不是網站，不是 App，也不用註冊帳號。<br>
它是一份寫得很細的說明書 —— 把「一個好站長該怎麼做事」寫下來，<br>
裝進你本來就在用的 AI 就好（Claude、Codex、Cursor 這一類）。

**它不會自己連上你的網站。**

要真的動手，得靠你的 AI、和你給它的權限。<br>
它管的是「該不該做、怎麼做才安全」。

### 安全設計

#### 七層安全網

每一個會寫入網站的操作，都必須依序走完：

1. **備份** — 匯出資料庫、打包檔案。失敗就換方案，四種都失敗才進入風險說明
2. **先給你看要改什麼** — 列出將要改的具體內容，不接受「優化 SEO」這種模糊說法
3. **確認** — 依風險等級取得你的明確同意
4. **可逆標記** — 每一項都標明「可逆」或「不可逆」
5. **先在測試站試** — 高風險操作先測試站
6. **留下操作紀錄** — 每個動作留一行紀錄，只增不改
7. **自動還原** — 失敗自動還原；還原失敗立即停止並交你手動步驟

#### 操作分級

| 級別 | 意思 | 站長怎麼做 |
|---|---|---|
| **G0 只看不改** | 不改任何東西 | 直接執行 |
| **G1 可逆變更** | 改內容但能還原 | 提案後等你確認 |
| **G2 高風險** | 改檔案、外掛、主題 | 必須明確同意 + 備份 + 先在測試站試 |
| **G3 禁止** | 不可逆或會毀站 | 預設拒絕，除非你用自己的話二次明確要求 |

G3 的具體清單：

- 直接寫入資料庫
- 刪掉 wp-content
- 改 wp-config 的資料庫憑證與安全金鑰
- 更換主題
- 停用全部外掛
- 重設資料庫
- 刪掉 Cloudways server

<br>

**而且 wp-config.php 有特別的規矩：**

只允許四個特定的設定項目可以改，其他一律不准。<br>
因為這個檔案一改錯，整站會變白畫面，連後台都進不去。

#### 弄壞了會怎樣

站長會**先備份才動手**，失敗會自動還原。

如果真的還原不了，它會立即停下來，<br>
並給你一份手動還原步驟（含備份識別碼與還原順序）。

### FAQ

**Q：免費嗎？**

是，永久免費，原始碼全部公開。你可以自己看、自己改。

**Q：需要會寫程式嗎？**

不需要。站長預設假設你不懂技術，會用白話和比喻說明。你可以隨時說「講詳細一點」切換成技術模式。

**Q：一定要用 Cloudways 嗎？**

不用。但四層快取的自動消退、伺服器層操作（重啟、SSL、備份還原）只有在 Cloudways 上才做得到。其他主機它會直接告訴你哪幾項不行。

**Q：它會自己改我的網站嗎？**

不會。每一個寫入操作都要你同意，而且會先列出「將要改什麼」讓你確認。

**Q：如果它改壞了怎麼辦？**

七層安全網的第一層就是備份，失敗會自動還原。你也可以在事前要求「先備份再做」。

**Q：支援哪些 AI？**

Claude Code、Codex、Cursor、OpenCode，以及任何支援 `SKILL.md` 格式的 Agent。

**Q：跟一般叫 AI 幫我改網站有什麼不同？**

一般 AI 會直接給你指令或直接動手。這個 skill 給它的是「判斷力」：什麼該做、什麼要先問、什麼絕對不能碰，以及出問題時怎麼收拾。

**Q：為什麼叫「站長」？**

因為它要模擬的不是「工具」，是「一個幫你顧網站的人」。
